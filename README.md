# Tommi – Was geht in Köln?

Web-Prototyp: interaktive 3D-Karte von Köln. Events leuchten auf ihren Häusern, je Kategorie mit eigener Farbe und Animation.

- Karte: [MapLibre GL JS](https://maplibre.org), Kacheln von [OpenFreeMap](https://openfreemap.org)
- Kartendaten: © [OpenStreetMap](https://www.openstreetmap.org/copyright)-Mitwirkende (ODbL)
- Gebäude-Infos: Nominatim und Overpass (OpenStreetMap)
- Icons: [Lucide](https://lucide.dev) (ISC)

Die Events sind Testdaten; Orte und Gebäude-Umrisse sind echt, das Programm ist erfunden.
